# v0.5.5 リリースノート（2026-10-28）

## 新機能

- 通知方式とタイミングをテンプレートに保存し、予定へ適用できます。「未指定」「通知なし」「既存通知を置換」「既存通知へ追加」を選べます。追加時は同じ方式・分数の重複を防ぎます。
- 予定色をテンプレートに保存できます。「未指定（変更しない）」「カレンダーの既定色」「指定色」を区別します。
- 新しい設定はJSONインポート／エクスポートにも保持されます。旧テンプレートでは通知・色を変更しません。

## 改善

- 通知設定は初期1行とし、「＋」で追加、「−」で削除できます。長い説明は折りたたみました。
- 小さい予定画面でも、説明欄・色設定欄を展開して適用できます。
- テンプレートを続けて選んだ場合は、処理中の適用を終えてから最後の選択を適用します。
- 適用を確認できない場合は成功扱いせず、対象項目と理由を知らせます。

## 対応範囲・既知の制限

- 通知設定は詳細画面の時刻付き予定に対応します。終日予定の通知設定には未対応です。
- 通知は最大5件、0〜40320分前です。方式・予定色の選択肢はGoogleカレンダーの画面によって利用できない場合があります。
- 小さい予定画面で高速切替後にホイールスクロールが効かなくなる症状は、完全には解消していません。
- 予定は自動保存しません。内容を確認してから利用者が保存してください。
- データは従来どおり端末内に保存します。追加の権限要求はありません。

更新前にテンプレートのJSONをエクスポートして保管してください。旧バージョンへ戻す場合、新しい通知・色の項目は保持されないことがあります。
