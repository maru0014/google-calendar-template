# Chrome Web Store 更新説明文 — v0.5.5

以下を更新内容として使用できます。

---

通知と予定色をテンプレートに保存できるようになりました。

- 通知方式・タイミングを保存して適用。「変更しない」「通知なし」「既存を置換」「既存に追加」を選べます。同じ通知の重複追加を防ぎます。
- 予定色は「変更しない」「カレンダーの既定色」「指定色」を区別して設定できます。
- 通知設定は初期1行。「＋」で追加、「−」で削除できるコンパクトな画面になりました。
- 小さい予定画面でも説明・予定色を適用できます。
- JSONインポート／エクスポートで新設定を保持し、旧テンプレートも引き続き利用できます。
- 連続したテンプレート選択の処理と、適用失敗時の案内を改善しました。

通知設定は詳細画面の時刻付き予定に対応し、最大5件・0〜40320分前です。終日予定の通知には未対応です。小さい予定画面で高速に切り替えた後、ホイールスクロールが効かなくなる症状は完全には解消していません。

追加権限はありません。テンプレートは端末内に保存します。Googleカレンダーの予定通知の入力を補助する機能であり、独自に通知を送信するものではありません。予定の内容を確認し、最後にご自身で保存してください。

更新前にテンプレートをJSONでエクスポートして保管することをおすすめします。
